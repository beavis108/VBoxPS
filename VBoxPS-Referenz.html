VBoxPS

VBoxPS

Modulversion 1.0.0 für Windows PowerShell 5.1 und PowerShell 7+

VBoxPS steuert Oracle VirtualBox aus PowerShell: VMs anlegen, klonen und löschen, starten und stoppen, Snapshots, Netzwerk und Storage konfigurieren, Betriebssysteme unbeaufsichtigt installieren und Befehle im Gast ausführen.

Installation

Kopieren Sie den Ordner VBoxPS in einen Modulpfad und importieren Sie das Modul. VBoxManage wird automatisch gefunden. Abweichende Installationen legen Sie mit Set-VBoxManagePath fest.

PowerShell
Copy-Item .\VBoxPS "$HOME\Documents\PowerShell\Modules\" -Recurse
Import-Module VBoxPS
Get-Command -Module VBoxPS

Schnellstart

PowerShell
Get-VBoxVM
Start-VBoxVM 'Win11-Lab' -WaitForGuestAdditions
New-VBoxSnapshot 'Win11-Lab' 'Vor Update'
Get-VBoxVM -Running | Stop-VBoxVM -Wait

Syntax

PowerShell

   [<CommonParameters>]

Beschreibung

Das Cmdlet Get-VBoxManagePath gibt den vollständigen Pfad der VBoxManage-Binary zurück, die das Modul verwendet.

Die Binary wird beim ersten Aufruf in dieser Reihenfolge gesucht: ein mit Set-VBoxManagePath gesetzter Pfad, die Umgebungsvariable VBOXPS_VBOXMANAGE, VBOX_MSI_INSTALL_PATH, VBOX_INSTALL_PATH, die Standard-Installationspfade (%ProgramFiles%\Oracle\VirtualBox, /usr/bin, /usr/local/bin, /Applications/VirtualBox.app) und zuletzt PATH. Wird keine Binary gefunden, löst das Cmdlet einen Fehler aus.

Beispiele

Beispiel 1: Verwendeten VBoxManage-Pfad anzeigen

PowerShell
Get-VBoxManagePath

Gibt z. B. C:\Program Files\Oracle\VirtualBox\VBoxManage.exe zurück.

Invoke-VBoxManage

Modul: VBoxPS

Ruft VBoxManage direkt auf – für alles, was das Modul nicht abdeckt.

Syntax

PowerShell
Invoke-VBoxManage
   [-ArgumentList] <String[]>
   [-Raw]
   [<CommonParameters>]

Beschreibung

Das Cmdlet Invoke-VBoxManage ruft VBoxManage mit beliebigen Argumenten auf. Verwenden Sie es für alles, was das Modul nicht direkt abdeckt.

Ohne -Raw gibt das Cmdlet die Ausgabezeilen zurück und löst bei einem Exit-Code ungleich 0 einen Fehler mit der Meldung von VBoxManage aus. Mit -Raw erhalten Sie ein Ergebnisobjekt und es wird kein Fehler ausgelöst.

Die Argumente werden korrekt maskiert, Leerzeichen und Anführungszeichen in Werten sind also unproblematisch.

Beispiele

Beispiel 1: Installierte Extension Packs anzeigen

PowerShell
Invoke-VBoxManage list extpacks

Beispiel 2: Exit-Code selbst auswerten

PowerShell
$r = Invoke-VBoxManage showvminfo 'Win11' --machinereadable -Raw
if ($r.ExitCode -ne 0) { Write-Warning $r.StdErr }

Beispiel 3: Host-Only-Netzwerk unter macOS anlegen

PowerShell
Invoke-VBoxManage hostonlynet add --name LabNet --netmask 255.255.255.0 --lower-ip 192.168.60.100 --upper-ip 192.168.60.200

VirtualBox 7 verwendet unter macOS Host-Only-Netzwerke statt Host-Only-Interfaces.

Legt fest, welche VBoxManage-Binary verwendet wird.

Syntax

PowerShell
Set-VBoxManagePath
   [-Path] <String>
   [-WhatIf]
   [-Confirm]
   [<CommonParameters>]

Beschreibung

Das Cmdlet Set-VBoxManagePath legt für die aktuelle Sitzung fest, welche VBoxManage-Binary das Modul verwendet. Das ist nötig, wenn VirtualBox an einem nicht standardmäßigen Ort installiert ist oder mehrere Versionen parallel vorhanden sind.

Beim Setzen werden die zwischengespeicherte Version, die Hilfetexte und die OS-Typ-Liste verworfen. Für eine dauerhafte Einstellung setzen Sie die Umgebungsvariable VBOXPS_VBOXMANAGE.

Beispiel 1: Installationsordner angeben

PowerShell

Verwendet D:\Tools\VirtualBox\VBoxManage.exe für alle weiteren Aufrufe.

Beispiel 2: Pfad dauerhaft über das Profil setzen

PowerShell
$env:VBOXPS_VBOXMANAGE = 'D:\Tools\VirtualBox\VBoxManage.exe'

In das PowerShell-Profil eingetragen, gilt die Einstellung für jede neue Sitzung.

Beschreibung

Das Cmdlet New-VBoxVM erstellt und registriert eine neue VM und gibt sie zurück.

Die VM erhält einen SATA-Controller SATA. Port 0 ist die Festplatte, falls -DiskSizeGB größer als 0 ist, Port 1 ein DVD-Laufwerk mit ISO oder leer. Die Bootreihenfolge ist DVD, dann Festplatte. Windows-Gäste bekommen standardmäßig den Grafikcontroller VBoxSVGA, andere VMSVGA.

PowerShell

Beispiel 2: Linux-Server im Bridged-Netz

PowerShell
$nic = (Get-VBoxBridgedInterface | Where-Object Status -eq 'Up')[0].Name
New-VBoxVM 'srv01' -OSType Ubuntu_64 -DiskSizeGB 40 -NetworkType Bridged -NetworkName $nic

Start-VBoxUnattendedInstall

Modul: VBoxPS

Bereitet eine unbeaufsichtigte OS-Installation vor und startet sie optional.

Syntax

Start-VBoxUnattendedInstall
   [-Name] <String>
   -IsoPath <String>
   -Credential <PSCredential>
   [-AdminPassword <SecureString>]
   [-FullUserName <String>]
   [-Hostname <String>]
   [-ProductKey <String>]
   [-ImageIndex <Int32>]
   [-Locale <String>]
   [-Country <String>]
   [-TimeZone <String>]
   [-Language <String>]
   [-InstallGuestAdditions]
   [-AdditionsIsoPath <String>]
   [-PostInstallCommand <String>]
   [-StartVM <String>]
   [-WhatIf]
   [-Confirm]
   [<CommonParameters>]

Beschreibung

Das Cmdlet Start-VBoxUnattendedInstall bereitet eine unbeaufsichtigte Installation des Betriebssystems vor und startet die VM standardmäßig headless. Die Installation läuft danach ohne Eingriff durch.

Passwörter werden ausschließlich über temporäre Dateien übergeben. Das Cmdlet erkennt selbst, ob die installierte VirtualBox-Version die Optionen --user-password-file (ab 7.1) oder --password-file erwartet.

Die VM braucht ein DVD-Laufwerk. New-VBoxVM legt immer eins an.

Beispiele

Beispiel 1: Windows 11 vollautomatisch installieren

PowerShell
$cred = Get-Credential labadmin
New-VBoxVM 'Win11-Lab' -OSType Windows11_64 -MemoryMB 8192 -CPUs 4 -DiskSizeGB 80 -Firmware EFI -EnableTpm -EnableSecureBoot
Start-VBoxUnattendedInstall 'Win11-Lab' -IsoPath 'D:\ISO\Win11.iso' -Credential $cred `
    -Hostname 'win11-lab.lab.local' -Locale de_DE -Country DE `
    -TimeZone 'W. Europe Standard Time' -ImageIndex 6 -InstallGuestAdditions
Wait-VBoxGuestAdditions 'Win11-Lab' -TimeoutSec 3600

Nach Wait-VBoxGuestAdditions ist der Gast bereit für Invoke-VBoxGuestCommand.

Beispiel 2: Ubuntu-Server mit Nachinstallation

PowerShell
Start-VBoxUnattendedInstall 'srv01' -IsoPath 'D:\ISO\ubuntu-24.04-live-server-amd64.iso' -Credential $cred `
    -Hostname 'srv01.lab.local' -TimeZone 'Europe/Berlin' -InstallGuestAdditions `
    -PostInstallCommand 'apt-get install -y openssh-server'
